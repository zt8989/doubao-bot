# zcode 载体：子智能体改用自带 CreateSession 分配 + 提示词按 agent 拆分

## Context

现状两个问题：
1. **子智能体裸奔**：router 提示词（`src/builtin/router-prompt.md`，3.5KB）只说「创建编码与对抗审查内部 sub agent」，完整模板只存在于旧外部会话路径的 orchestrator/dispatch 提示词里——zcode 路径下 router 派活全靠即兴发挥。
2. **单会话单轮干全部**：router 在自己一条会话的一轮里串行做决策+编码+审查，无隔离、不可观察。

用户决定：**用 ZCode 自带的 CreateSession 会话工具**为编码/审查各开独立根会话（不用自建 app-server 集成、不用 .zcode/agents 定义），**提示词按 agent 拆成共享目录下的独立文件**，每个智能体只读自己的那份。已探明 zcode 模型工具注册表里有 `CreateSession/SendToSession/WaitSessions/ReadSession`（cli 面有自己的 schema）；headless 下是否注入需一次实机探针。

## 实现步骤

### 1. 拆分提示词：新增共享智能体提示词文件
- 新增 `foreman/src/builtin/agents/coder.md`、`reviewer.md`：内容从 `orchestrator-prompt.md` 的两段 blockquote 模板（编码 23-48 行、审查 52-86 行）扩写成**独立完整提示词**（身份、输入=任务包、执行要求、输出契约原样保留；开头加一句「本文件是你的岗位提示词，收到任务包后严格按本文件执行」）。
- 旧 `orchestrator-prompt.md`/`dispatch-prompt.md` **不动**（dws 兼容路径仍自包含可用）。

### 2. 路径解析：`builtin-prompts.mjs` 加 `builtinAgentPromptPath(name)`
- `fileURLToPath(new URL("./agents/<name>.md", import.meta.url))` 返回绝对路径（沿用现 `builtinPrompt` 的模块相对模式，src/dist 双份各自成立）；校验文件存在，缺失抛错。

### 3. router 分配协议：`core/router.mjs` deliver() 首句注入 + `router-prompt.md` 增强
- `router-prompt.md` 职责 2/3 改写：编码/审查智能体用**自带 CreateSession 工具**开独立根会话分配，不要在自己会话内串行干编码/审查。
- `router.mjs` deliver() 首句动态注入两个**绝对路径**（运行时算，src/dist 各自正确）：
  ```
  ## 子智能体分配协议
  编码智能体提示词文件：<abs>/agents/coder.md
  审查智能体提示词文件：<abs>/agents/reviewer.md
  分配方式：用你的 CreateSession 工具为每个子智能体开独立会话（project 用 ListProjects 里与工程路径匹配的项目，取不准就用当前项目）；
  会话首句固定为两段：第一段「先完整阅读你的提示词文件 <绝对路径>，严格遵照执行」，第二段注入任务包（工单键/正文/验收标准/工程与基线/约束/复审反馈）。
  等待用 WaitSessions，读结果用 ReadSession（view=summary）；审查意见修复用 SendToSession 续说同一编码会话（同工单始终复用同一条编码会话）。
  会话工具不可用时才回退：Agent 工具 + 相同提示词文件路径注入。
  ```

### 4. 实机探针（实现期第一步，1 次极小调用）
`zcode -p` 问：工具列表里有无 CreateSession/WaitSessions/ReadSession/SendToSession、ListProjects 返回什么、project 参数怎么选。据此微调协议文案（project 语义）；若会话工具不可用 → 停下向用户回报（兜底回退分支已写进协议，但主方案失效需要用户定夺）。

### 5. 顺带修已发现的 bug：router 死绑定 24h 不自愈
`core/router.mjs` routerOnce 的 catch（~129-139 行）：投递失败且错误为「目标会话不存在」（zcode `session_missing` / dws「侧边栏里没有任务」文案）时，清掉 `rec.convId` 再落账，让下一轮重试直接新建，不再等 24h。（今天切载体时手动止血过一次的根因）

### 6. 测试
- `test/router.test.mjs` 扩展：新建路径的首句断言包含两个提示词文件绝对路径与「CreateSession」协议段（fixture dws 捕获首句即可，与载体无关）。
- 新增/扩展 builtin-prompts 测试：`builtinAgentPromptPath` 返回存在的文件路径。
- 更新 `skills/foreman/SKILL.md` 与 `foreman/README.md`：子智能体=独立 zcode 根会话 + 共享提示词文件的说明。

## 边界
- 子智能体会话是 router 私有编排，不进 foreman 账本/watch（与现「内部 sub agent」口径一致）；治理（并发/等待/续问）全靠 router 按协议自理。
- 提示词文件引用一律绝对路径（delivered 会话无 --cwd，bundle 探明 zcode 默认 cwd 不可靠）。
